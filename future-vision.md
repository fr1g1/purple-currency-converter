## Future vision
When we get to the point where everything will be fully agentic, the developers will focus on:
1. Architecture
    - critical point in development
    - developer knows about future plans and have to think ahead
2. Scalability and maintenance
    - agents works better as small parts handle specific task
    - developer has context about whole project and future visions
3. AI orchestration
4. Review results
   - control quality of results
   - effect on performance
5. Security
    - developer has to ensure, that agent did not miss critical weakpoints, edge cases or think ahead which point can became critical in long-term future

Developer also have to:
- clearly define problems
- translating bussiness goals
- coordinate AI orchester and cooperate with other developers

Developers will become more system and security designer, strategist and quality controller. AI will not have full context about project, unless until we have AGI.

**AI agents are still a tool that needs to be managed.**
