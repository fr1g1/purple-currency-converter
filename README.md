# Purple Currency Converter

Expo mobile app for converting currencies with a purple-themed UI.

## Tech Stack

- Expo
- React Native
- TypeScript
- TanStack Query
- AsyncStorage
- `@react-native-picker/picker`

## Local Setup

### 1. Install dependencies

```bash
npm install
```

### 2. Add environment variables

Create a `.env` file in the project root and add your Fixer API key:

```bash
EXPO_PUBLIC_FIXER_APP_ID=your_fixer_api_key_here
```

### 3. Start the app

```bash
npx expo start
```

### Tested only on Android
